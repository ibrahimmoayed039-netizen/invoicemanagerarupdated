# دفتر الفواتير — نسخة أندرويد (Kotlin)

هذا هيكل مشروع أندرويد أصلي (Kotlin) بديل عن نسخة Electron لسطح المكتب. البداية:

- **4 أقسام رئيسية بالشاشة الأولى**: العملاء، الفواتير، التسديد، الإعدادات.
- **العملاء**: شاشة فعلية كاملة (قائمة + إضافة عميل) مربوطة بقاعدة بيانات محلية (Room/SQLite).
- **الفواتير، التسديد، الإعدادات**: شاشات مؤقتة (Placeholder) حالياً — نبنيها بالتدريج بعد هذا.

## البنية التحتية الجاهزة
- Room (قاعدة بيانات محلية) بجداول: Customer، SaleInvoice، Payment — تقابل نفس حقول نسخة سطح المكتب (db.js).
- ViewBinding مفعّل، Material 3، دعم RTL كامل (`supportsRtl="true"`).
- **GitHub Actions** (`.github/workflows/build-apk.yml`): يبني APK تلقائياً في كل Push على فرع `main`، ويرفعه كـ Release منفصل برقم إصدار جديد (`v1.0.<رقم التشغيل>`) — فتحصل نسخة جديدة كل مرة تضيف ميزة وترفعها.

## ملاحظة
هذا المجلد الآن جزء من مستودع مُدمج مع نسخة سطح المكتب (Electron) الشقيقة. خطوات الرفع على GitHub والبناء التلقائي (يبني الملفين معاً بكل push) موجودة بملف `README.md` بالمجلد الجذر للمستودع (فوق هذا المجلد).

## ملاحظة مهمة
هذا المشروع **لم يُبنَ فعلياً هنا** (لا يوجد Android SDK ولا محاكي بهذه البيئة) — الكود مكتوب باتّباع الأنماط القياسية لـ Android/Kotlin/Room وتم فحص التركيب المنطقي، لكن أول بناء فعلي سيحصل تلقائياً عبر GitHub Actions فور رفعه، أو عندك على جهازك بفتحه بـ Android Studio. إذا ظهر أي خطأ بالبناء (نادر لكن ممكن باختلاف إصدارات الأدوات)، ابعتلي رسالة الخطأ من تبويب Actions وأصلحها فوراً.

## الخطوة التالية
قلّي أي شاشة تحب نبنيها فعلياً بعد هذي (الفواتير أو التسديد أو الإعدادات) ونكملها بنفس الأسلوب.
