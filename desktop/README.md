# دفتر الفواتير — برنامج سطح مكتب (Electron)

برنامج سطح مكتب بواجهة عربية (RTL) لإدارة:
- **سجل العملاء** (إضافة/تعديل/حذف، وملف لكل عميل يعرض فواتيره ورصيده)
- **بحث شامل سريع** من أي شاشة (شريط البحث أعلى الصفحة) للوصول مباشرة إلى أي عميل أو فاتورة بيع/شراء عبر الاسم أو رقم الهاتف أو رقم الفاتورة
- **فواتير البيع والشراء** (بنود متعددة، خصم، دفعات جزئية)
- **المستحقات** (المبالغ المستحقة لك من العملاء، والمستحقة عليك للموردين)
- **السجل والتاريخ** (سجل زمني كامل لكل الفواتير والدفعات، قابل للتصفية)
- **الطباعة** لوصولات البيع/الشراء وتقارير كشف الحساب، مع **معاينة قبل الطباعة الفعلية**، عبر نظام الطباعة العادي لنظام التشغيل (أي طابعة مثبّتة).

جميع البيانات تُخزَّن محلياً في ملف JSON داخل مجلد بيانات المستخدم الخاص بنظام التشغيل، وتبقى محفوظة بعد إغلاق البرنامج وإعادة فتحه.

---

## 1. المتطلبات

- [Node.js](https://nodejs.org) الإصدار 18 أو أحدث (يتضمن npm).
- نظام التشغيل: ويندوز أو ماك أو لينكس.

## 2. التشغيل أثناء التطوير

```bash
npm install
npm start
```

سيفتح البرنامج في نافذة سطح مكتب مباشرة.

## 3. بناء ملف تثبيت (exe / dmg / AppImage)

```bash
# ويندوز
npm run dist:win

# ماك
npm run dist:mac

# لينكس
npm run dist:linux
```

سيتم إنشاء ملفات التثبيت داخل مجلد `dist/` (هذا المجلد غير مرفوع على GitHub بحسب `.gitignore`).

> ملاحظة: لبناء نسخة ويندوز (exe) يفضّل تنفيذ الأمر من داخل ويندوز نفسه، وكذلك بناء dmg من داخل ماك، بسبب قيود التوقيع والأدوات الخاصة بكل نظام. **أو استخدم البناء التلقائي عبر GitHub الموضّح في القسم 7 بدلاً من ذلك.**

## 4. مكان تخزين البيانات

يُنشئ البرنامج ملف `data.json` تلقائياً في المسار التالي:

| النظام | المسار |
|---|---|
| ويندوز | `%APPDATA%\invoice-manager-ar\data.json` |
| ماك | `~/Library/Application Support/invoice-manager-ar/data.json` |
| لينكس | `~/.config/invoice-manager-ar/data.json` |

يمكنك أخذ نسخة احتياطية في أي وقت من تبويب **الإعدادات → تصدير نسخة احتياطية (JSON)**.

يمكنك أيضاً **استعادة** نسخة احتياطية سابقة من نفس التبويب عبر **استيراد نسخة احتياطية (JSON)** — مع ملاحظة أن هذه العملية تستبدل كل البيانات الحالية (يطلب البرنامج تأكيداً قبل التنفيذ).

## 5. الطباعة

- من كل فاتورة: زر **🖨 طباعة** يفتح معاينة داخل البرنامج بنفس شكل المستند.
- من تبويب **المستحقات** أو **ملف العميل**: زر **كشف حساب** يطبع تقرير كشف حساب كامل للعميل.
- من تبويب **السجل والتاريخ**: زر **طباعة تقرير** يطبع قائمة الحركات المعروضة حالياً (بعد التصفية).
- بعد المعاينة، زر **طباعة** يفتح نافذة الطباعة الخاصة بنظام التشغيل حيث يمكن اختيار الطابعة وعدد النسخ ومعاينة إضافية قبل التأكيد.
- بجانبه زر **⭳ حفظ PDF** يحفظ نفس المستند مباشرة كملف PDF على القرص دون المرور بنافذة الطباعة.

```

├── .github/

├── src/
│   ├── index.html    # هيكل الواجهة (شريط جانبي + تبويبات)
│   ├── styles.css    # التصميم (عربي RTL)
│   └── app.js         # منطق الواجهة، النماذج، الطباعة
├── assets/
│   └── icon.png       # أيقونة التطبيق
├── package.json
├── .gitignore
├── .gitattributes
├── LICENSE
└── README.md
```
